智慧饼 {{VERSION}} - Windows 使用说明

一、如何启动
1. 先将本文件夹完整解压（不要在压缩包里直接运行）
2. 双击「智慧饼.exe」

二、若打不开（尤其是 Windows 10）
1. 双击「安装依赖.bat」
2. 或手动运行 MicrosoftEdgeWebView2Setup.exe 安装 WebView2
3. 本包已内置 VC++ 运行库 DLL（msvcp140.dll / vcruntime140.dll / vcruntime140_1.dll）

三、系统要求
- Windows 10 / 11（64 位）
- Microsoft Edge WebView2 Runtime（Win11 一般已自带；Win10 可能需安装）

四、其他说明
- 登录状态保存在本机用户目录，不会随安装包发送给别人
- 请分发整个文件夹/zip，不要只发单个 exe
